# Aziz Academy — deploy runbook

Live at **https://aziz-academy.com** (Vercel-hosted, Cloudflare DNS).

## TL;DR

```powershell
.\scripts\deploy_web.ps1 --prod
```

That runs the whole pipeline: build → patch → minify → strip → deploy → validate. Each step exits non-zero on failure so the pipeline halts early.

## Prerequisites

- `flutter` on PATH (latest stable)
- `vercel` CLI logged in to the right team (`vercel whoami`)
- `python` 3.10+ for the post-build scripts
- (DNS / certs already provisioned — done once on 2026-05-08)

## What the pipeline does

| Step | Script | Purpose |
|---|---|---|
| 1 | `flutter build web` | Release build with `--no-source-maps`, `--pwa-strategy=none`. Tree-shake-icons is ON (default) — every icon used in the app resolves to a static `Icons.X` constant, verified by grep for any `IconData(...)` constructor. Saves ~1.6 MB on `MaterialIcons-Regular.otf` |
| 2 | `scripts/patch_canvaskit_local.py` | Rewrites `flutter_bootstrap.js` so CanvasKit loads from `/canvaskit/` instead of `gstatic.com` (gives us the 1-year immutable cache) |
| 3 | `scripts/minify_json_pools.py` | Strips whitespace from 248 JSON pools (~10% smaller) |
| 4 | inline `Remove-Item` | Strips unused canvaskit variants (`chromium/`, `skwasm*`, `wimp*`) |
| 5 | `vercel deploy --prod` | Ships to https://aziz-academy.com |
| 6 | `scripts/validate_production_deploy.py` | Validates the live site against the regression checklist |

## Validator checklist

Each of these has bitten us in real life and is now caught automatically:

- root `/` returns 200
- CSP allows `fonts.gstatic.com` in `connect-src` AND `font-src` (otherwise emojis don't render)
- `flutter_bootstrap.js` is patched to use `/canvaskit/` AND `canvasKitVariant: "full"` (otherwise Chrome tries `/canvaskit/chromium/` which we strip)
- `/canvaskit/canvaskit.{js,wasm}` are reachable
- `/_vercel/insights/script.js` script tag is either commented out OR Vercel actually serves it as JavaScript (Web Analytics needs to be enabled in the Vercel dashboard)
- `/.well-known/security.txt` serves with `text/plain` content-type
- `sitemap.xml` parses as valid XML
- `robots.txt` disallows admin/diag routes
- `aziz-academy.vercel.app` 308-redirects to `aziz-academy.com`
- HSTS header is present
- `main.dart.js` is between 1 MB and 5 MB on disk (catches accidental dependency bloat OR a broken build)

## Manual checks after first deploy of the day

1. **Hard reload in your browser** (`Ctrl+Shift+R` on Windows, `Cmd+Shift+R` on Mac) — `index.html` has `must-revalidate` but a stale tab can hold the old CSP/bootstrap.
2. **DevTools → Application → Storage → "Clear site data"** if anything still looks off (nukes service workers + caches + localStorage for the origin).
3. **Open the home screen** and confirm: emoji icons render, sound toggle works, language toggle flips AR ↔ EN, top-bar tooltips appear on hover.

## Production routes smoke test

`scripts/verify_production_routes.py` reads `sitemap.xml` and HEAD-checks every URL in parallel. Currently 137 URLs, all should return 2xx.

```powershell
python scripts/verify_production_routes.py
```

Run it independently when you want a fast confidence check without re-deploying.

## Footguns we've already paid for

- **Service-worker cache hell**: a previous build registered a SW that aggressively cached `main.dart.js`. Builds now use `--pwa-strategy=none` AND `web/index.html` ships a synchronous SW killswitch. Don't re-enable PWA strategy until you have a clear cache-busting plan.
- **Tree-shake-icons is ON** (default Flutter behavior). MaterialIcons-Regular.otf ships at ~22 KB instead of 1.6 MB. The validator includes a check that fails if it ever ships >200 KB. If you ever see icons rendering as tofu boxes, the cause is almost certainly a `IconData(0x...)` constructor that bypasses the static analyzer — grep for `IconData(` and replace with the matching `Icons.X` constant.
- **Performance baseline (production, 2026-05-10)**: HTML 5.3 KB / main.dart.js 1.25 MB (br) / canvaskit.wasm 2.9 MB (br) / Amiri 211 KB (br) / Cairo ~140 KB (br) / NotoColorEmoji 2.9 MB. TTFB ~300 ms. Total cold-cache wire weight ~7 MB; warm cache is just HTML revalidation + main.dart.js conditional GET. The validator gates main.dart.js brotli wire at 1.6 MB (~30% headroom over current).
- **CanvasKit chromium variant**: Flutter bootstrap defaults to loading the smaller chromium-specific variant on Chrome/Edge from `/canvaskit/chromium/`. Our strip step deletes that subdirectory to save ~24 MB on disk, so we MUST force `canvasKitVariant: "full"` in the bootstrap config — that's what `patch_canvaskit_local.py` does.
- **CSP fonts.gstatic.com**: Flutter web fetches Noto Sans Arabic + Roboto fallback fonts from `fonts.gstatic.com`. Our CSP allows `www.gstatic.com` for canvaskit AND `fonts.gstatic.com` for fallback fonts — both are needed.
- **Noto Color Emoji must be COLRv1, not CBDT**: we bundle `NotoColorEmoji.ttf` locally via pubspec. The googlefonts/noto-emoji repo ships two variants — the bitmap CBDT/CBLC `NotoColorEmoji.ttf` (~10.6 MB) and the vector COLRv1 `Noto-COLRv1-noflags.ttf` (~2.9 MB). **CanvasKit cannot render CBDT** — the cmap claims coverage but bitmap glyph rendering fails inside the painter, and the FontFallbackManager won't fall through to gstatic because it thinks the local font covers the codepoint. Always bundle the COLRv1 variant. To verify: `python -c "import struct; d=open('assets/fonts/NotoColorEmoji.ttf','rb').read(); n=struct.unpack('>H',d[4:6])[0]; tags=[d[12+i*16:12+i*16+4].decode() for i in range(n)]; print('COLR' in tags and 'CPAL' in tags)"` should print `True`.
- **`late SharedPreferences _prefs` is a race trap in AsyncNotifier**: a `late` field initialized in async `build()` throws `LateInitializationError` if any setter (or listener-triggered effect) runs before build resolves. We've now switched all 19 affected notifiers to `SharedPreferences? _prefs;` with `_prefs ??= await SharedPreferences.getInstance();` at the top of every async method. If you write a new AsyncNotifier that touches SharedPreferences, follow the same pattern — don't reach for `late`.
- **Vercel Insights**: `/_vercel/insights/script.js` only works if Web Analytics is enabled in the Vercel dashboard. Without that, the script tag 404s and the browser logs a MIME-type error. Tag is currently commented out in `web/index.html`; uncomment once analytics is enabled.
- **`.vercelignore` blocks `*.txt`**: defensive against accidentally shipping `*.txt` build artifacts. The `!build/web/robots.txt` and `!build/web/.well-known/security.txt` re-includes are critical — if you add another `.txt` asset under `build/web/` you must whitelist it the same way.
- **SPA rewrite catch-all**: `vercel.json` rewrites everything to `/index.html` so deep links work. Static-file paths must be excluded explicitly: currently `diag.html`, `404.html`, `sitemap.xml`, `robots.txt`, `og-image.png`, `.well-known`, `_vercel`. Add new static asset paths to that lookahead.

## Rollback

Vercel keeps every deploy. To roll back:

```bash
vercel rollback <deployment-url>
```

Or via dashboard: vercel.com/sfahhads-projects/aziz-academy → Deployments → click previous deploy → Promote to Production.

## HSTS preload

The HSTS header now includes the `preload` directive. After ~7 days of stable serving (counted from 2026-05-08), submit at https://hstspreload.org for permanent inclusion in browser preload lists.
