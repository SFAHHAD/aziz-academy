PART II — IN-APP AI AGENTS FOR A KIDS/TEENS LEARNING GAME
================================================================================
Scope note: Agents *inside* the product, not back-office automation. Ordered by
retention/learning impact for ages 6–12 (Aziz Academy core demographic).

────────────────────────────────────────────────────────────────────────────────
A. CORE LEARNING LOOP — the non-negotiables
────────────────────────────────────────────────────────────────────────────────

A1. Adaptive Difficulty Agent
- Watches success rate, time-per-question, retries, hint usage, streak length.
- Rebalances upcoming question difficulty in real time to keep the child in
  the "flow zone" — neither bored nor frustrated.
- Single biggest retention lever in edtech games. Build this first.
- Aziz Academy hook: questions already carry `difficulty: 1|2|3` (sciences,
  general_quiz, iq). Wire a per-child rolling accuracy window and weight pool
  sampling toward the band that gives ~75–85% success.

A2. Personal Tutor Companion ("Aziz" character)
- An in-game character that gives *hints*, never answers.
- Speaks age-appropriate Arabic/English, encourages effort over correctness
  ("Smart try! Look at the second word again").
- Triggers: wrong-answer streak >= 2, idle >15s on a question, child taps "?".
- Voice: warm, short sentences, never sarcastic. TTS via existing
  ttsServiceProvider.

A3. Mistake-Pattern Agent
- Detects *why* a child fails repeatedly — not just *that* they fail.
  Examples: confuses subtraction-with-borrowing, swaps Riyadh/Tehran,
  mixes up photosynthesis vs. respiration.
- Triggers a 30-second mini-lesson or 3-question targeted drill instead of
  showing the same level again.
- Builds on the existing struggling-questions list (`missCount >= 2`) plus
  category-level error clustering.

────────────────────────────────────────────────────────────────────────────────
B. PERSONALIZATION — picks what plays next
────────────────────────────────────────────────────────────────────────────────

B1. Learning Path Agent
- Replaces static module ordering with a dynamic next-up recommendation.
- Inputs: stars per module, recent miss rate, days since last play of each
  topic, child-stated goals (parent setup), upcoming school exam window.
- Output: ordered queue of 3–5 next sessions with one-line rationale
  ("Sciences review — you missed 2 last time. 4 questions, ~3 min").

B2. Content Recommender
- "Kids like Sara also enjoyed X" surfacing of new modules/topics, scoped to
  *learning* signals (not engagement-only) to avoid the YouTube trap.
- Cold start: difficulty + locale + age band → curated starter packs.

B3. Interest Agent
- Asks 5 onboarding questions ("animals or rockets?", "drawing or building?")
  and biases content theme picks toward those interests for the first month —
  e.g., math word problems set in space if rockets, in zoos if animals.

────────────────────────────────────────────────────────────────────────────────
C. ENGAGEMENT & MOTIVATION
────────────────────────────────────────────────────────────────────────────────

C1. Reward & Quest Agent
- Generates *personalized* daily/weekly missions tuned to the child's level
  and weakest area: "Beat 3 fraction levels to unlock the dragon pet."
- Static rewards get boring fast; rotation is the lever.
- Aziz Academy hook: existing `dailyMissionFor()` is currently calendar-based
  (7-day rotation incl. Survival/Boss); switch to child-state-based next.

C2. Encouragement Agent
- Detects frustration signals: rapid retries (<5s between wrong answers),
  rage-quits (mid-quiz exit after a wrong), drop in accuracy >20% within a
  session.
- Intervenes with a break suggestion, an easier "warm-up" question, or a
  kind word from the companion. Never shaming.

C3. Streak Coach
- Beyond "you have a 7-day streak" — predicts streak risk ("You usually play
  before bedtime, it's 9pm — quick 2-minute round?") and sends a *single*
  gentle reminder at the family-approved window. Crucially: never spammy.

C4. Celebration Agent
- Picks the right celebration moment & intensity. Small win → confetti emoji;
  module mastery → animated badge + parent notification. Avoids alert fatigue
  by capping celebrations per session.

────────────────────────────────────────────────────────────────────────────────
D. SOCIAL & SAFETY (non-negotiable for under-13)
────────────────────────────────────────────────────────────────────────────────

D1. Safe-Chat Moderator
- Real-time message filter for any chat / co-op feature.
- Layered: profanity blocklist (per-locale, AR + EN) → PII detector (phone
  numbers, addresses, school names) → LLM classifier for tone (bullying,
  scams, grooming patterns) → human review queue for edge cases.
- Default-deny for anything below confidence threshold.

D2. Friendly-Competition Agent
- Runs age-matched challenges and small-group leaderboards (5–20 peers, never
  global). Global leaderboards are demotivating for kids who aren't top-5.
- Rotates winners' spotlight across multiple metrics (most improved, longest
  streak, kindest hint-giver) so different kids win different weeks.

D3. Co-op Tutor Agent
- For 2-player modes: pairs kids with complementary strengths so they
  actually help each other instead of one carrying the other.

────────────────────────────────────────────────────────────────────────────────
E. PARENT-FACING (still in-app)
────────────────────────────────────────────────────────────────────────────────

E1. Parent Dashboard Agent
- Generates a plain-language weekly story:
  "This week Sara mastered multiplication and struggled with reading
   comprehension. Try reading the attached story together — it covers the
   exact words she missed."
- Beats raw charts. Make it scannable in 30 seconds.

E2. Co-Play Coach
- For "Co-Play Mode" (already a setting in Aziz Academy): suggests 5-minute
  joint sessions parents can run with the child, with prompts the parent can
  read aloud. Lowers parent guilt about screen time.

E3. Homework Assistant Agent
- Parent uploads/scans a school worksheet → agent generates 3 practice
  questions in the same style, in the child's language. Never replaces school
  work; supplements.

────────────────────────────────────────────────────────────────────────────────
F. CONTENT-SIDE AGENTS (live alongside the kid)
────────────────────────────────────────────────────────────────────────────────

F1. Question Generator Agent
- Generates new questions in-style of existing pools, in both AR and EN, with
  difficulty tagging. Always passes through F2 before publishing.
- Caps: rate-limited per child to prevent infinite-content fatigue.

F2. Content Safety & Curriculum Agent
- Vets generated/imported content against:
  · age-appropriate vocabulary (reading-age check, AR + EN)
  · cultural sensitivity (Saudi/Gulf context for Aziz Academy)
  · curriculum alignment (matches grade-level standards)
  · factual accuracy (LLM cross-check + source citation)
- All four must pass.

F3. Localization Agent
- The bilingual rule extends to future languages. This agent:
  · auto-translates new EN content to AR (and future locales) with kid-voice
  · preserves cultural concepts (adapts US-centric examples to local)
  · flags strings that don't translate well for human review.

────────────────────────────────────────────────────────────────────────────────
G. ACCESSIBILITY & INCLUSION
────────────────────────────────────────────────────────────────────────────────

G1. Reading-Support Agent
- Detects struggling readers (slow tap-to-answer time on text-heavy questions
  vs. fast on image-heavy) and auto-enables read-aloud + larger text.
- Gives dyslexia-friendly font as a one-tap toggle when triggered.

G2. Attention-Aware Agent
- Detects ADHD-pattern signals (very short sessions, frequent topic-hopping,
  high re-tap rate). Suggests shorter rounds (3 questions instead of 10) and
  more visual rewards. Never labels — just adapts.

G3. Vision/Color Agent
- Auto-detects color-blindness from a 30-second onboarding mini-game and
  rewires color-coded UI accordingly. Quietly, no labels.

────────────────────────────────────────────────────────────────────────────────
H. EXTRINSIC LEARNING — beyond the quiz
────────────────────────────────────────────────────────────────────────────────

H1. Story-Mode Agent
- Wraps a weekly module into a 5-minute illustrated story where the child is
  the hero. Math becomes "fix the broken bridge by solving 3 problems".
  Sciences becomes "save the coral reef by identifying these creatures".
- Generated per child, in their language, themed to their interests (B3).

H2. Real-World Quest Agent
- Off-screen tasks: "Look around the kitchen — find 5 things shaped like a
  cylinder, then come back and tell me." Encourages screen-balance and
  attaches abstract concepts to physical reality.
- Parents sign off (one tap) so kids can't fake completion.

H3. Voice-Q&A Agent
- Child holds a button and *asks* a question by voice ("Why is the sky
  blue?"). Agent answers in 2–3 kid-friendly sentences with a follow-up
  question to keep curiosity alive. AR + EN.

────────────────────────────────────────────────────────────────────────────────
I. INFRASTRUCTURE — what these agents need
────────────────────────────────────────────────────────────────────────────────

I1. Event Bus
- Every interaction emits a typed event: question_started, question_answered
  {correct, latency_ms, hints_used}, session_ended, etc.
- Without this, every agent above is guessing. Build this first or in
  parallel with A1.

I2. Per-Child State Store
- Persistent profile: skill estimates per topic (Bayesian or simple ELO),
  recent error log, frustration signals, interests, accessibility flags,
  parent prefs.
- On-device first (privacy) — sync to cloud only with parent opt-in.

I3. Privacy & Data Minimization
- Under-13 means COPPA / Saudi Personal Data Protection Law / GDPR-K.
- Every agent must declare: what data, how long retained, where processed.
- Default: process on-device when feasible; redact PII before any cloud call.

I4. Agent Orchestrator
- A small "router" decides which agent to wake on a given event. Avoids the
  trap of every agent listening to every event (latency + battery).
- Priority queue: safety > learning > engagement > personalization.

I5. Observability for Agents
- Each agent logs: trigger, decision, outcome (did the kid recover? did they
  rage-quit anyway?). Without this you can't tell which agent is helping vs.
  hurting.

────────────────────────────────────────────────────────────────────────────────
J. ROADMAP — what to build first
────────────────────────────────────────────────────────────────────────────────

If you build only two: A1 (Adaptive Difficulty) + A2 (Tutor Companion).
Together they fix the two biggest drop-off causes: "too hard" and "stuck with
no help." Everything else compounds on top.

Phased rollout (recommended for Aziz Academy):

Phase 1 — Foundation (4–6 weeks)
  · I1 Event Bus, I2 State Store, I3 Privacy boundaries
  · A1 Adaptive Difficulty (rule-based, no LLM yet)
  · A2 Tutor Companion (rule-based hints, scripted lines)

Phase 2 — Smart loop (6–8 weeks)
  · A3 Mistake-Pattern Agent
  · C1 Reward & Quest Agent (replaces static daily missions)
  · C2 Encouragement Agent

Phase 3 — Personalization (8 weeks)
  · B1 Learning Path Agent
  · B3 Interest Agent
  · E1 Parent Dashboard Agent (plain-language summary)

Phase 4 — Content & accessibility (ongoing)
  · F1+F2 Question Generator + Safety
  · G1 Reading Support, G2 Attention-Aware
  · H1 Story Mode

Phase 5 — Social (only when you have a critical mass)
  · D1 Safe-Chat Moderator (BEFORE D2/D3 ever ship)
  · D2 Friendly Competition

────────────────────────────────────────────────────────────────────────────────
K. HONEST CAVEATS
────────────────────────────────────────────────────────────────────────────────

1. Each agent needs DATA. Without I1+I5 in place, agents become guessers and
   you'll ship features that look smart but aren't.
2. LLM latency on mobile/web is 1–3s. For agents that fire mid-quiz (A2, C2)
   pre-compute hints/responses at question-load time, not on-demand.
3. Cost: an LLM call per question != viable. Default to on-device rules; reach
   for an LLM only at decision boundaries (story generation, parent summary).
4. Parents > kids on safety decisions. Any agent that changes content scope
   (D1, F1, H3) must be visible & adjustable in the parent dashboard.
5. Cultural fit: AR-first content for Aziz Academy means agents that
   default-test in Arabic, not "translate-from-English." Different idioms,
   different humor, different reading levels.
6. Don't ship all of these. Pick the 4–6 that move the needle hardest for
   *your* users; the rest are decoration.
